应用简介

VoiceNB 是一个 macOS 本地语音工作区，用于录音、导入音频或视频、离线转录、降噪、编辑和导出字幕或文本。语音识别、语音活动检测和降噪模型均随应用提供，在本机运行。

主要功能

  • 使用麦克风录音，支持暂停和继续。
  • 拖入或选择常见音频、视频文件，并提取第一条音轨。
  • 使用本地 Whisper 模型转录，支持自动检测或手动选择语言。
  • 使用本地 DeepFilterNet 模型进行标准或强力降噪。
  • 编辑带时间戳的转录文本，按分类整理记录。
  • 导出 SRT、VTT、带时间戳 TXT 或纯文本 TXT。
  • 复制转录文本和整理提示词到剪贴板，供用户自行选择的外部工具使用。

数据位置

录音、导入后的 M4A 音频、转录索引和分类索引默认保存在 ~/Library/Application Support/VoiceNB/，通常包括 transcripts.json、categories.json 和每条记录对应的 M4A 文件。临时中间文件在处理完成或失败后由应用尝试删除。

常见问题

没有声音或无法开始录音

打开“系统设置 → 隐私与安全性 → 麦克风”，允许 VoiceNB 使用麦克风并重新启动录音。确认系统能识别输入设备，并关闭可能独占麦克风的其他应用。

导入失败

确认文件包含音轨，优先使用 MP3、M4A、WAV、AAC、FLAC、MP4、MOV 或 M4V。MKV、AVI、WMV、RMVB、OGG、OPUS 和 WEBM 可能不受支持。沙盒模式下请通过文件选择器或拖放授权文件访问。

转录失败或结果不准确

在“设置”中确认 Whisper、VAD 和降噪模型均显示为“就绪”。嘈杂录音可先启用降噪，清晰录音通常应关闭降噪；手动选择实际说话语言通常比自动检测更稳定。重新转录会覆盖当前转录文本和手动编辑内容，但不会覆盖原始音频。

找不到记录

检查 VoiceNB 应用支持目录是否存在。若手动删除或移动其中的 M4A 文件，记录仍可能出现在索引中但无法播放或重新转录。删除记录时，应用会同时删除本地音频文件和索引记录。

外部 AI 整理如何工作

VoiceNB 不内置云端 AI。选择“整理”后，应用将提示词和转录文本复制到 macOS 剪贴板，用户可粘贴到自己选择的 AI 或文本工具。发送前请确认目标服务的隐私政策和数据处理方式。

Overview

VoiceNB is a local macOS voice workspace for recording, importing audio or video, offline transcription, denoising, editing, and subtitle or text export. Speech recognition, VAD, and denoising run locally using bundled models.

Key features

  • Record with pause and resume.
  • Import common audio/video files and extract the first audio track.
  • Transcribe with bundled Whisper using automatic or selected language.
  • Apply standard or strong local DeepFilterNet denoising.
  • Edit timestamped transcript cues and organize records by category.
  • Export SRT, VTT, timestamped TXT, or plain TXT.
  • Copy transcript text and cleanup prompts to the clipboard for user-selected tools.

Data location

Recordings, imported M4A audio, transcript indexes, and category indexes are stored by default at ~/Library/Application Support/VoiceNB/. Temporary files are removed where possible after processing.

Troubleshooting

Recording cannot start

Go to System Settings → Privacy & Security → Microphone, allow VoiceNB, and restart recording. Check the input device and close apps that may exclusively use the microphone.

Import fails

Make sure the file contains an audio track. Prefer MP3, M4A, WAV, AAC, FLAC, MP4, MOV, or M4V. Other formats may not be supported; use the file picker or drag and drop for sandbox access.

Transcription fails or is inaccurate

Confirm that Whisper, VAD, and denoising models are ready in Settings. Denoising can help noisy recordings, while clear recordings generally work best with it off. Selecting the spoken language manually is often more reliable. Retranscription overwrites the current transcript and manual edits, not the original audio.

Cleanup with external AI

VoiceNB has no built-in cloud AI. Cleanup copies a prompt and transcript to the macOS clipboard. The user decides whether to paste it into an external tool and should review that service’s privacy terms first.
