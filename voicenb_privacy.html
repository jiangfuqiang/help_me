隐私政策

VoiceNB 本地处理录音、导入媒体和离线转录，不提供账号、云同步或网络上传。

生效日期：2026-08-25适用版本：0.1.0

1. 我们处理哪些数据

VoiceNB 可能在本机处理麦克风录音、用户主动选择或拖入的音频和视频及其第一条音轨、离线转录文本、时间戳、识别语言、处理状态、标题、分类、创建时间、降噪状态，以及用户主动粘贴回应用的整理结果。应用未发现账号、联系人、定位、相机、照片库、云同步、广告、分析、遥测或网络上传功能。

2. 处理方式和存储位置

录音、音频提取、降噪、语音活动检测和 Whisper 语音识别在本机完成。默认数据目录为 ~/Library/Application Support/VoiceNB/，其中保存音频文件以及 transcripts.json、categories.json 等本地索引。临时中间文件会在处理结束、取消或失败后尝试删除。应用不提供账号服务器，也不会因正常录音或转录上传数据。

3. 剪贴板和外部 AI

“整理”功能会把提示词和转录文本写入 macOS 剪贴板，方便用户粘贴到自己选择的 AI 或文本工具。VoiceNB 不会替用户调用或选择外部服务，也无法控制这些服务是否保存、训练或处理内容。应用也支持在用户主动使用相关界面时从剪贴板预填整理结果。

4. 保留和删除

数据会保留在本机，直到用户删除记录、手动删除 VoiceNB 应用支持目录，或操作系统及用户自己的备份策略将其删除。删除记录会删除对应的本地音频和索引；导出文件、剪贴板、系统备份和外部服务副本不受控制。

5. 安全性说明

VoiceNB 使用 macOS 应用沙盒、用户选择的文件访问权限和应用支持目录进行本地存储。当前未提供额外的应用级端到端加密或云端密钥管理。请使用 macOS 账户安全、磁盘加密、备份和设备访问控制保护数据。

6. 儿童和敏感信息

VoiceNB 不是医疗、法律、金融或身份验证工具。语音识别可能产生错误，请勿仅依据转录结果作出高风险决定。处理他人声音前，请确认拥有必要的告知和授权。

7. 政策变更和联系

数据处理方式发生变化时，应更新本文的生效日期和内容。隐私问题可通过以下 GitHub Issues 联系维护者；请勿公开发布原始音频、转录全文或其他敏感信息。

1. Data we process

VoiceNB may process locally microphone recordings; audio or video selected or dropped by the user and its first audio track; offline transcripts, timestamps, language, and processing state; titles, categories, creation dates, denoising state; and cleanup results pasted back by the user. The current project contains no accounts, contacts, location, camera, photo-library, cloud-sync, advertising, analytics, telemetry, or network-upload implementation.

2. Processing and storage

Recording, audio extraction, denoising, voice activity detection, and Whisper transcription run on the device. Data is stored by default at ~/Library/Application Support/VoiceNB/, including audio files and indexes such as transcripts.json and categories.json. Temporary files are removed where possible after processing. Normal recording and transcription do not upload data to a VoiceNB server.

3. Clipboard and external AI

Cleanup writes a prompt and transcript to the macOS clipboard so the user can paste them into a chosen AI or text tool. VoiceNB does not select or call an external service and cannot control whether it stores, trains on, or otherwise processes the content. The app may prefill a cleanup-result field from the clipboard when the user chooses that workflow.

4. Retention and deletion

Data remains on the device until the user deletes a record, removes the application-support directory, or the operating system and the user’s backup policy remove it. Deleting a record removes its local audio and index entry; exports, clipboard contents, backups, and external copies remain outside the app’s control.

5. Security

VoiceNB uses the macOS App Sandbox, user-selected file access, and the application-support directory. The current implementation does not add application-level end-to-end encryption or cloud key management. Protect the device with a secure account, disk encryption, backups, and access controls.

6. Sensitive use

VoiceNB is not a medical, legal, financial, or identity-verification tool. Transcription can be inaccurate; obtain appropriate notice and consent before processing another person’s voice.

7. Changes and contact

Update this policy when data practices change. Privacy questions may be raised in the SottoVoice GitHub repository. Do not post recordings, full transcripts, or sensitive personal information publicly.
