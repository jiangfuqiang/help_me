🆘 常见问题 FAQ

基础使用

Q: 如何添加文件夹？
A: 点击左侧边栏顶部的"+"按钮，选择"Add Folder"，然后选择包含 Markdown 文件的文件夹。
Q: 如何在普通模式和开发者模式之间切换？
A: 点击工具栏右侧的模式切换按钮，可以在"普通"和"开发"模式之间切换。
Q: 支持哪些文件格式？
  • Markdown 文件 (.md, .markdown)
  • 纯文本文件 (.txt)
  • Textbundle 文件 (.textbundle)
Q: 如何导出文件？
A: 点击菜单栏的"文件" > "导出"，可以选择导出为 HTML 或 PDF 格式。

Mermaid 图表

Q: 如何创建 Mermaid 图表？

使用代码块语法：

```mermaid
graph LR
    A --> B
```
Q: 如何放大查看 Mermaid 图表？
A: 将鼠标悬停在图表上，点击右上角出现的"🔍 放大"按钮。
Q: Mermaid 图表支持哪些类型？
A: 支持流程图、时序图、甘特图、类图、状态图、饼图等所有 Mermaid 标准图表类型。

数学公式

Q: 如何插入数学公式？

行内公式：$E = mc^2$

独立公式块：

$$
\int_{a}^{b} f(x) dx
$$
Q: 支持哪些 LaTeX 语法？
A: 支持标准的 LaTeX 数学语法，使用 KaTeX 渲染引擎。

文件搜索

Q: 如何搜索文件？

在左侧边栏顶部的搜索框中输入关键词，可以选择搜索范围：

  • 文件名：只搜索文件名
  • 正文：只搜索文件内容
  • 文件名和正文：全文搜索

图片处理

Q: 如何插入图片？
  1. 拖拽图片到编辑器
  2. 使用菜单"插入" > "图片"
  3. 使用 Markdown 语法：![描述](图片路径)

🔧 故障排除

应用无法启动

症状：双击应用图标后没有反应

解决方案：

症状：点击"Add Folder"后无法选择文件夹

解决方案：

  1. 确保您有该文件夹的读取权限
  2. 尝试选择其他文件夹
  3. 重启应用后重试

🆘 FAQ

Basic Usage

Q: How to add a folder?
A: Click the "+" button at the top of the left sidebar, select "Add Folder", then choose a folder containing Markdown files.
Q: How to switch between normal and developer mode?
A: Click the mode toggle button on the right side of the toolbar to switch between "Normal" and "Developer" modes.
Q: What file formats are supported?
  • Markdown files (.md, .markdown)
  • Plain text files (.txt)
  • Textbundle files (.textbundle)
Q: How to export files?
A: Click "File" > "Export" in the menu bar, then choose to export as HTML or PDF.

Mermaid Diagrams

Q: How to create Mermaid diagrams?

Use code block syntax:

```mermaid
graph LR
    A --> B
```
Q: How to zoom in on Mermaid diagrams?
A: Hover over the diagram and click the "🔍 Zoom" button that appears in the top right corner.
Q: What types of Mermaid diagrams are supported?
A: Supports flowcharts, sequence diagrams, Gantt charts, class diagrams, state diagrams, pie charts, and all standard Mermaid diagram types.

Math Formulas

Q: How to insert math formulas?

Inline formula: $E = mc^2$

Block formula:

$$
\int_{a}^{b} f(x) dx
$$
Q: What LaTeX syntax is supported?
A: Supports standard LaTeX math syntax, rendered using KaTeX engine.

File Search

Q: How to search files?

Enter keywords in the search box at the top of the left sidebar. You can choose the search scope:

  • Filename: Search filenames only
  • Content: Search file content only
  • Filename and Content: Full-text search

Image Handling

Q: How to insert images?
  1. Drag and drop images to the editor
  2. Use menu "Insert" > "Image"
  3. Use Markdown syntax: ![description](image-path)

🔧 Troubleshooting

App Won't Start

Symptom: No response after double-clicking the app icon

Solution:

  1. Check if macOS version meets requirements (macOS 13.0+)
  2. Try reinstalling the app
  3. Check Console logs (Applications > Utilities > Console)

Cannot Add Folder

Symptom: Unable to select folder after clicking "Add Folder"

Solution:

  1. Ensure you have read permissions for the folder
  2. Try selecting a different folder
  3. Restart the app and retry
